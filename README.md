# q3-issue-agent

제품 지표 데이터를 받아, 좋아 보이는 집계 지표에 속지 않고, **진짜로 심각한 문제 '하나'를 근거와 함께 제안**하는 작은 CLI 에이전트.

## 무엇을 하나

동네 기반 구인구직 매칭 퍼널(공고→지원→매칭)의 합성 데이터 위에서:

1. **생성기**(`src/gen/`)가 8주치 데이터를 만들고, "집계는 개선처럼 보이는데 특정 세그먼트가 곪은" 함정 3개를 심는다. 정답은 `answers/ground_truth.json`에만 기록한다.
2. **탐지기**(`src/agent/`)가 세그먼트×기간별 지표를 결정론적으로 집계하고, 표면 vs 세그먼트 괴리를 스캔해 후보를 추려 **단 하나**로 좁힌다. 정답 파일에는 접근할 수 없다.
3. **채점기**(`score.py`)가 제안을 정답과 대조해 정탐/오탐/미탐을 판정한다. 채점 전에 탐지기 소스가 정답 쪽을 참조하지 않는지 정적 검사한다(위반 시 채점 거부).

## 재현 (파이썬 표준 라이브러리만, 설치 불필요)

```bash
python3 run.py                  # 생성 → 탐지 → 채점 한 방 (시드 42)
python3 run.py --eval-seeds 5   # 시드 5개 반복 채점 → 정탐률/오탐률 집계
python3 run.py --clean-seeds 5  # 함정 없는 데이터 참음성 확인 — 헛제안 0이어야 정상
```

산출물: `out/report.md`(사람용 리포트), `out/proposal.json`(채점용), `out/score.json`(채점 결과).

## 측정 결과 (완성 기준)

| 검사 | 결과 |
|---|---|
| 함정 데이터 15개 시드 (42–46, 100–109) | **정탐 15 / 오탐 0 / 미탐 0**, primary 적중 13 |
| 클린 데이터 20개 시드 (42–61) | **헛제안 0** |
| 격리 가드 | 탐지기에 정답 참조 코드를 일부러 넣으면 채점 거부(exit 2) 확인 |

primary 미적중 2건(시드 43·46)은 T1의 실현 신호가 우연히 약하게 뽑힌 시드로, 탐지기가 실현 데이터 기준 더 심각한 다른 함정(T2)을 고른 정당한 판단이다(DECISIONS.md 참고).

## 원칙

- **수치는 전부 코드가 계산한다.** LLM은 규칙 설계 단계에만 개입했고(그 추론과 실패는 DECISIONS.md/FAILURES.md에 기록), 실행 파이프라인은 100% 결정론적이다. 리포트의 서술은 템플릿이고 모든 숫자는 코드 산출값의 인용이다.
- **정답과 탐지기의 격리.** 함정 파라미터는 `src/gen/traps.py`에만 존재하고, `answers/`는 채점기만 읽는다. 이름 계약(`src/contract.py`)은 어휘만 공유한다.
- **문제는 하나만.** 후보가 여럿이면 심각도 점수(상대 악화 × 볼륨 비중 × 지표 가중치)로 좁히고, 폐기한 후보와 사유를 리포트에 남긴다.

## 탐지 로직 요약

- 기간 비교: 전반 4주(baseline) vs 후반 4주(current), 축: 지역/직종/평일주말/거리구간/직종×요일.
- 후보 조건: 절대 악화 ≥ 5pp ∧ 초과 악화(excess, 전체 추세 대비) ≥ 5pp ∧ 상대 악화 ≥ 30% ∧ 표본 ≥ 50 ∧ BH(FDR α=0.05) 유의성 통과.
- dedup: ⓪ 직접 표준화 — 다른 축 구성비로 설명되는 악화 폐기 → ① 같은 세그먼트 다중 지표는 퍼널 상류 대표 → ② 2차원 축과 성분 축 중복 제거.

## 구조

```
run.py              # 원커맨드 실행기
score.py            # 독립 채점기 (answers/를 읽는 유일한 소비자 + 격리 가드)
src/contract.py     # 이름 계약 (축/지표 어휘만 — 함정 정보 없음)
src/gen/generate.py # 기간 대칭 베이스 데이터 생성
src/gen/traps.py    # 함정 주입 + 정답 기록
src/agent/metrics.py  # 세그먼트×기간 지표 집계
src/agent/rules.py    # 괴리 스캔 (임계값 + BH 유의성)
src/agent/severity.py # 심각도 점수·dedup·최종 1개 선택
src/agent/report.py   # proposal.json + report.md
```

## 한계 / 범위 밖

- 심슨의 역설(mix-shift) 함정은 stretch로 보류했다 — 핵심(평균에 가려진 세그먼트 악화 탐지)을 먼저 확실히 하기 위해.
- 대시보드, 실시간, 예측 모델링, 다중 문제 제안은 의도적으로 범위 밖.
- 설계 결정·번복은 `DECISIONS.md`, 실패·오탐·LLM 판단 오류 사례는 `FAILURES.md`에 시간순으로 있다.
